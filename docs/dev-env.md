### Configs

We need to go with Ctrl/Cmd + ,

| Config                                                     | Effect                                                                |
| ---------------------------------------------------------- | --------------------------------------------------------------------- |
| `"terminal.integrated.defaultProfile.windows": "Git Bash"` | Changes the default terminal to use `gitbash`                         |
| `"workbench.sideBar.location": "right"`                    | Changes the activity bar to appear at the right side(not left)        |
| `"workbench.editor.showTabs": false`                       | Hide all the tabs in Vscode                                           |
| `"editor.minimap.enabled": false`                          | Hide mini code map                                                    |
| `"editor.scrollbar.vertical": auto`                        | Hide scroll bar and only show when scrolling                          |
| `"editor.overviewRulerBorder": false`                      | Hides the ruler marks in the left scrollin bar                        |
| `"editor.hideCursorInOverviewRuler": true`                 | Hides the cursor position check                                       |
| `"editor.formatOnSave": true`                              | auto formats any file when save                                       |
| `"editor.guides.indentation": false`                       | Disables VSCode Indentation (since we have already Indentator plugin) |
| `"indenticator.width": 1`                                  | makes the left ruler to be included with a really light color         |
| `"indenticator.color.dark": "rgba(255,255,255,0.1)"`       | makes the left indentation line to be with a transparent color        |
| `"editor.marchBrackets": "never"`                          | Uses subtle match extension to underline the brackets in the code     |
| `"breadcrumbs.enabled": false`                             | Disables the path in the tabs                                         |
| `"editor.glyphMargin": false`                              | Debugger points visualization                                         |
| `"workbench.statusBar.visible": false`                     | Hides the status bar (below)                                          |
